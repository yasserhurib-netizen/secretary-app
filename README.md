# سكرتيرتي - تطبيق أندرويد

## الحصول على التطبيق (APK) بدون برامج على جهازك
1. أنشئ حسابًا مجانيًا في github.com (من الحاسوب أسهل).
2. اضغط New repository وسمِّه secretary-app ثم Create repository.
3. اضغط "uploading an existing file" وارفع محتويات هذا المجلد كلها، ومنها المجلد المخفي `.github`.
   إن لم يُرفع `.github` فأنشئ الملف بنفسك: Add file ثم Create new file، واكتب الاسم
   `.github/workflows/android.yml` والصق محتوى الملف الموجود بالمجلد نفسه، ثم Commit.
4. افتح تبويب Actions. سيبدأ البناء تلقائيًا (3 إلى 8 دقائق)، أو اضغط Run workflow.
5. عند ظهور علامة خضراء افتح التشغيلة، ونزّل ملف **secretary-apk** من قسم Artifacts. ستجد داخله app-debug.apk.
6. انقل الملف إلى هاتفك وافتحه، واسمح بالتثبيت من مصدر غير معروف عند السؤال.

## أول تشغيل على الهاتف
- اسمح بالإشعارات، وبالمنبّهات الدقيقة إن فتح الهاتف صفحة إعداداتها.
- من إعدادات الهاتف: البطارية، ثم اختر "غير مقيّد" لتطبيق سكرتيرتي، حتى لا تُلغى التنبيهات.
- للقراءة الصوتية العربية: ثبّت "خدمات الكلام من Google" ونزّل اللغة العربية.

## كيف تعمل التنبيهات
عند إضافة موعد يجدول التطبيق إشعارين في نظام أندرويد نفسه: قبل الموعد بالمدة المحددة، وعند الموعد. لذلك تصل حتى لو كان التطبيق مغلقًا.
القراءة بالصوت تعمل عند فتح التطبيق أو ضغط الإشعار، لأن أندرويد لا يسمح بالكلام من تطبيق مغلق.
يجدول التطبيق الشهر القادم، ويجدّد الجدولة كل مرة تفتحه.
